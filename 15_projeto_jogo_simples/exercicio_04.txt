EXERCÍCIO 04 — Placar e Regras do Jogo
Dificuldade: ⭐⭐⭐ Difícil

====================================================
PROBLEMA
====================================================

Implemente o sistema de pontuação, exibição do placar e regras
de vitória. O jogo deve ter rodadas e um vencedor.

====================================================
RESULTADO ESPERADO
====================================================

Funcionalidades:
- Placar exibido no topo: "Jogador 1: 0 | Jogador 2: 0"
- Primeiro a 5 pontos vence
- Mensagem de vitória exibida ao chegar a 5
- Botão "Jogar Novamente" após vitória
- Bola reinicia após cada ponto
- Velocidade da bola volta ao normal a cada ponto

====================================================
TAREFAS
====================================================

1. Crie objeto placar {esquerda: 0, direita: 0}
2. Exiba o placar no canvas com fonte grande
3. Crie condição de vitória (primeiro a 5)
4. Implemente tela de vitória
5. Implemente função reiniciarJogo()

====================================================
DICA
====================================================

Placar:
  let placar = { esquerda: 0, direita: 0 };

  function desenharPlacar() {
      ctx.fillStyle = "white";
      ctx.font = "40px Arial";
      ctx.textAlign = "center";
      ctx.fillText(placar.esquerda, canvas.width / 4, 50);
      ctx.fillText(placar.direita, (canvas.width / 4) * 3, 50);
  }

Condição de vitória:
  let jogoAtivo = true;

  function verificarVitoria() {
      if (placar.esquerda >= 5) {
          jogoAtivo = false;
          mostrarVitoria("Jogador 1");
      } else if (placar.direita >= 5) {
          jogoAtivo = false;
          mostrarVitoria("Jogador 2");
      }
  }

Tela de vitória:
  function mostrarVitoria(vencedor) {
      ctx.fillStyle = "rgba(0,0,0,0.7)";
      ctx.fillRect(0, 0, canvas.width, canvas.height);
      ctx.fillStyle = "#FFD700";
      ctx.font = "50px Arial";
      ctx.textAlign = "center";
      ctx.fillText(vencedor + " Venceu!", canvas.width/2, canvas.height/2 - 20);
      ctx.font = "24px Arial";
      ctx.fillText("Clique para jogar novamente", canvas.width/2, canvas.height/2 + 30);
  }

Reiniciar:
  canvas.addEventListener("click", function() {
      if (!jogoAtivo) {
          reiniciarJogo();
      }
  });

  function reiniciarJogo() {
      placar = { esquerda: 0, direita: 0 };
      resetarBola();
      jogoAtivo = true;
  }
