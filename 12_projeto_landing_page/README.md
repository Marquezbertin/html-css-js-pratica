# Módulo 12 — Projeto: Landing Page Responsiva

## O que você vai aprender

Neste projeto, você vai aplicar tudo que aprendeu nos módulos anteriores para criar uma landing page completa, profissional e responsiva do zero. Este projeto serve como prática integrada de HTML, CSS e responsividade.

## Teoria

### O que é uma Landing Page?

Uma landing page é uma página web projetada com um único objetivo: converter visitantes em leads ou clientes. Elas são usadas em campanhas de marketing e anúncios.

### Estrutura de uma Landing Page

```
1. Navbar ............. Navegação fixa no topo
2. Hero Section ...... Destaque principal com CTA
3. Features .......... Benefícios/principais características
4. Como Funciona ..... Passo a passo do serviço
5. Depoimentos ....... Prova social
6. Preços ............ Planos disponíveis
7. FAQ ............... Perguntas frequentes
8. CTA Final ......... Chamada para ação final
9. Footer ............ Informações de contato
```

### Princípios de Design

1. **Hierarquia visual**: O mais importante é grande e visível
2. **Whitespace**: Espaço em branco melhora a leitura
3. **Contraste**: Botões de destaque contrastam com o fundo
4. **Consistência**: Fontes, cores e espaçamento uniformes
5. **Responsividade**: Funciona em qualquer dispositivo

### Checklist de Responsividade

- [ ] Navbar fecha em mobile (hambúrguer)
- [ ] Textos legíveis em telas pequenas
- [ ] Imagens não estouram a largura
- [ ] Botões grandes o suficiente para toque
- [ ] Grid muda de colunas conforme a tela
- [ ] Padding/margin adequados em todas as seções
