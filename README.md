> Um curso completo de desenvolvimento web para iniciantes, com exercícios práticos e mini-projetos reais. Ideal para quem nunca programou ou quer reforçar o básico.

## Sobre

Este repositório faz parte do **Laboratório Tech Social** — uma iniciativa para democratizar o acesso à educação em tecnologia. Aqui você vai aprender HTML, CSS e JavaScript do zero, com exercícios progressivos e projetos que você pode colocar no seu portfólio.

## Como Usar

1. **Clone** o repositório:
   ```bash
   git clone https://github.com/laboratorio-tech-social/html-css-js-pratica.git
   ```
2. **Siga a ordem** dos módulos (01 a 15)
3. Leia o **README.md** de cada módulo para a teoria
4. Resolva os **exercícios** (arquivos `.txt`) na ordem indicada
5. Crie seus próprios arquivos `.html`, `.css` e `.js` para praticar
6. Abra os arquivos no navegador para ver os resultados

## Pré-requisitos

- Um **computador** com acesso à internet
- Um **navegador** moderno (Chrome, Firefox ou Edge)
- Um **editor de código** (recomendamos o [VS Code](https://code.visualstudio.com/))
- Vontade de aprender!
