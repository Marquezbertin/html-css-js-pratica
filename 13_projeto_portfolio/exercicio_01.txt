EXERCÍCIO 01 — Header + Hero do Portfólio
Dificuldade: ⭐⭐ Médio

====================================================
PROBLEMA
====================================================

Crie o cabeçalho e a seção principal do seu portfólio. O hero
deve ter sua foto, nome, profissão e um botão para ver projetos.

====================================================
RESULTADO ESPERADO
====================================================

Header + Hero com:
- Navbar com logo (seu nome) e links
- Hero com foto circular à esquerda
- Texto à direita: seu nome, cargo e descrição curta
- Botão "Ver Projetos" e link para LinkedIn/GitHub
- Fundo escuro (tema dark)
- Layout em duas colunas

====================================================
TAREFAS
====================================================

1. Crie "index.html" e "styles.css" com tema escuro
2. Crie navbar responsiva com flexbox
3. Crie hero com layout 2 colunas (foto + texto)
4. Adicione foto circular com border-radius: 50%
5. Adicione links sociais com ícones (unicode ou SVG)

====================================================
DICA
====================================================

Layout hero 2 colunas:
  .hero {
      display: flex;
      align-items: center;
      justify-content: center;
      gap: 60px;
      padding: 80px 20px;
      min-height: 100vh;
  }

Foto circular:
  .foto-perfil {
      width: 250px;
      height: 250px;
      border-radius: 50%;
      object-fit: cover;
      border: 4px solid var(--accent);
  }

Links sociais:
  .social-links a {
      display: inline-flex;
      width: 45px;
      height: 45px;
      border: 1px solid var(--gray);
      border-radius: 50%;
      align-items: center;
      justify-content: center;
      color: white;
      text-decoration: none;
      transition: all 0.3s;
  }
  .social-links a:hover {
      background: var(--primary);
      border-color: var(--primary);
  }
