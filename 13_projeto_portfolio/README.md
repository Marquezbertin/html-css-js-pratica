# Módulo 13 — Projeto: Portfólio Pessoal

## O que você vai aprender

Crie um site portfólio profissional para mostrar seus projetos, habilidades e experiência. Este projeto é perfeito para usar como cartão de visitas online.

## Teoria

### O que é um Portfólio?

Um portfólio é uma vitrine digital do seu trabalho. Ele deve:
1. **Apresentar quem você é** (seção "Sobre")
2. **Mostrar seus projetos** (galeria/grid de projetos)
3. **Demonstrar habilidades** (lista de skills)
4. **Facilitar contato** (formulário ou links)

### Estrutura de um Portfólio

```
1. Header ............ Logo + navegação
2. Hero/Sobre ........ Apresentação pessoal
3. Habilidades ....... Skills técnicas
4. Projetos .......... Galeria de trabalhos
5. Experiência ....... Timeline profissional
6. Contato ........... Formulário ou links
7. Footer ............ Redes sociais + copyright
```

### Dicas de Design para Portfólio

1. **Minimalismo**: Menos é mais. Não sobrecarregue a página
2. **Consistência**: Use no máximo 2-3 fontes e 3-4 cores
3. **Hierarquia**: Destaque seus melhores projetos
4. **Personalidade**: Mostre quem você é, não só o que faz
5. **Performance**: Imagens otimizadas e código limpo
