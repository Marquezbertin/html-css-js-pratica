EXERCÍCIO 06 — Jogo de Adivinhação
Dificuldade: ⭐⭐⭐ Difícil

====================================================
PROBLEMA
====================================================

Crie um jogo onde o computador escolhe um número aleatório entre
1 e 100 e o jogador tenta adivinhar. O jogo deve dar dicas
("maior" ou "menor") e contar quantas tentativas foram feitas.

====================================================
RESULTADO ESPERADO
====================================================

Um jogo com:
- Título "Adivinhe o Número (1 a 100)"
- Campo de input para digitar o palpite
- Botão "Palpite" para enviar
- Mensagem de dica: "Maior!" ou "Menor!"
- Contador de tentativas
- Mensagem de vitória quando acertar
- Botão "Novo Jogo" para reiniciar
- Histórico dos palpites feitos

====================================================
TAREFAS
====================================================

1. Crie "adivinhacao.html" com estrutura HTML5 completa
2. Gere número aleatório com Math.random()
3. Crie função para verificar o palpite
4. Use if/else para dar dicas de maior/menor
5. Registre tentativas e histórico em um array

====================================================
DICA
====================================================

Gerar número aleatório:
  let numeroSecreto = Math.floor(Math.random() * 100) + 1;

Verificar palpite:
  function verificar() {
      let palpite = parseInt(document.getElementById("palpite").value);
      tentativas++;

      if (palpite === numeroSecreto) {
          mensagem = "Parabéns! Você acertou em " + tentativas + " tentativas!";
      } else if (palpite < numeroSecreto) {
          mensagem = "Maior! Tente um número maior.";
      } else {
          mensagem = "Menor! Tente um número menor.";
      }

      historico.push(palpite);
  }

Para atualizar a página:
  document.getElementById("mensagem").innerText = mensagem;
  document.getElementById("tentativas").innerText = "Tentativas: " + tentativas;

Para reiniciar:
  function novoJogo() {
      numeroSecreto = Math.floor(Math.random() * 100) + 1;
      tentativas = 0;
      historico = [];
  }
